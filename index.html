Sawaal jawaab
 

  
Product ka colour/design badal jayega?
Nahi. Har image prompt me “PRODUCT LOCK” rule jaata hai — shape, colour, design, pattern, logo, material, size sab same. Sirf background, light aur camera angle badalta hai.

  
Non-stop mode kya hai?
Engine ek batch ke baad khud naye scene soch kar aur images banata rehta hai. Jab kaafi ho jaye to “✅ Bas ho gaya” dabao — turant ruk jayega.

  
Images kahan jaati hain?
Har image ke niche ⬇️ Download — file tumhare Downloads folder me. Server pe kuch save nahi hota.

  
HSN aur GST sahi hoga?
Engine sabse近 sahi HSN suggest karta hai, par final confirm apne CA se karwa lo — galat HSN pe notice aa sakta hai.

  
Listing text copy kaise karu?
Har field pe “Copy” button hai, aur “📋 Poori listing copy karo” se sab ek saath clipboard me aa jata hai.
